# canvas-icon-picker
Obsidian Canvas icon picker: 418+ Material and Lucide icons, supports Chinese fuzzy search, color palettes, direct style changes within the canvas, and automatically cleans up unreferenced SVGs. Obsidian Canvas 图标选择器：418+ Material 与 Lucide 图标，支持中文模糊搜索、色卡、画布内直接改样式，并自动清理无引用的 SVG。
