# Canvas Icon Picker

作者：BACK

给 Obsidian Canvas 加一个「插入图标」面板：搜索、拖入、调样式、收藏、导入自定义 SVG。

## 安装（本仓库已装好，无需重复）

插件目录：`.obsidian\plugins\canvas-icon-picker\`，并在 `.obsidian\community-plugins.json` 中登记。
安装后重启 Obsidian，在「设置 → 第三方插件」中确认 **Canvas Icon Picker** 已启用。

手动安装方式：把本文件夹（`manifest.json` / `main.js` / `styles.css` / `icons.json`）整个复制到
`<你的库>\.obsidian\plugins\canvas-icon-picker\`，重启 Obsidian 后启用。

## 在哪点

打开任意 `.canvas` 文件，画布右上角的悬浮工具条里会出现一个 **shapes（形状）图标**的按钮，位置就在齿轮「画布设置」按钮的正上方。
点它 → 右上角弹出图标面板。

## 图标库（v1.1 已扩容）

- **Material Symbols/Icons 418 个**：内置中文名、分类、5 种官方形态（`filled / outlined / round / sharp / two-tone`）。
- **Lucide 全量**：Obsidian 自带图标集，全部可插入，自带「线稿 / 粗线」两种形态。
- **自定义 SVG**：底栏「导入 SVG」导入任意图标，形态为「原始」。
- 每个图标实际有几种形态取决于资源本身（例如 `bolt` 只有填充，`arrow_back` 有 5 种），样式面板只列出可用的形态。

## 面板用法

| 操作 | 结果 |
| --- | --- |
| 在搜索框输入 | 实时模糊搜索；支持子序列匹配（`swd` → sword），内置中文别名与 Material 中文名（剑、盾、地图、闪电、骷髅、齿轮…） |
| 左键按住图标拖动 | 拖到画布任意位置松手，即在该处插入图标节点 |
| 左键单击图标 | 在当前画布视野中心插入 |
| 图标右上角 ★ | 收藏 / 取消收藏；切到「收藏」选项卡只显示收藏过的 |
| 右键图标 | 弹出样式面板：颜色、形态、边框开关、「颜色组」色卡；面板会自动贴到图标左侧/右侧，不遮住被右键的图标 |
| 选项卡 | 全部 / 收藏 / 按分类（箭头、信号、游戏、媒体、文件、人物、设备、地图、物品、时间、工具、自然、编辑、交流 + Lucide + 自定义），鼠标滚轮可横向滚动；分类读不到时会用内置分类清单兜底，不会出现空选项卡 |
| 拖面板**左/右边缘** | 改宽度：右边缘右拉变宽、左拉变窄；左边缘左拉变宽、右拉变窄；宽度变化时**列数自动增减、图标尺寸不变**（不是缩放） |
| 拖面板下 / 右下角 | 改高度；右下角可同时改宽高；高度变化时显示的行数增减，其余滚动 |
| 底栏「移动」按钮 | 按住不放拖动，整个面板跟着指针移动；位置会记住，下次打开回到原处（设置里可恢复默认位置） |
| 面板右上角图钉 | 固定面板：固定后点画布、加卡片、插入图标都不会关窗；不固定则插入一个就自动关 |
| 底栏「导入 SVG」 | 从本地选一个或多个 `.svg`，加入图标库（存进插件配置，不占库文件） |

颜色：跟随主题 / 强调色 / 红橙黄绿青蓝紫粉灰白黑（自动去重）+ 末尾「＋」自定义取色。
颜色下方会显示**当前色卡名称 + 当前颜色色块/HEX**；点色卡里的颜色时，这里同步切换。
颜色右侧的 `⌄` 打开「颜色组」：内置「游戏常用」「中性描线」两组色卡，可「＋ 新增色卡」保存自己的配色，也可向已有色卡追加颜色或删除色卡；当前颜色所属的色卡会描边。
**点某张色卡的名字**（或最上方的「基础色」）：顶部那排快速颜色会切换成这张色卡的颜色，之后从这里取色；**右键任意色卡颜色**可以「删除该颜色」，删除只影响色卡，不会改动已插进画布的图标。
形态：**填充 / 轮廓 / 圆角 / 直角 / 双色**（Material），**线稿 / 粗线**（Lucide），**原始**（自定义）；按图标实际资源数量显示。
边框：给图标加一个圆角方框，做成「按钮」样式。

## 在画布里直接改图标样式（v1.2.4）

- **左键单击画布中已插入的图标**（按下后不拖动），会弹出这个图标的样式面板；再点同一个图标可收起。
- 面板里的颜色、形态、边框开关会**直接应用到当前这个节点**，不会改动图标面板里的全局默认样式，也不影响同图标生成的其他节点。
- 每次修改会生成一个带节点后缀的专属 SVG，并替换节点引用的文件；**节点的位置、尺寸、连线都保持不变**。
- 左键按住拖动仍然是移动节点，不会误触样式面板（位移超过 5px 视为拖动）。
- 老版本插入的图标也能识别：按文件名反查图标与形态，并从 SVG 推断颜色与是否带边框。

## 删除图标后的文件清理（v1.2.5）

- 在白板里删除图标节点后，插件会延迟约 4 秒检查这个 SVG 是否还有任何引用。
- 会扫描库内所有 `.canvas` 文件的节点和文本引用；**只有确认没有任何白板再用它时**，才删除 `Canvas Icons` 里对应的自动生成 SVG。
- 同一个 SVG 被多个节点共用时不会误删；删除最后一个引用后才会清理。
- 在画布里单独改样式后，旧的那份无引用 SVG 也会被自动回收。
- 只处理符合插件生成规则的文件，自己手动画的 `my-own-art.svg` 这类文件不会被删。
- 设置页新增「清理无引用的图标」，可手动扫描整个库，清掉以前遗留下来的孤儿文件。

## 插入的图标是怎么存的

- 每次插入会按「图标 + 形态 + 颜色 + 边框」生成一个确定性 SVG 文件，放在库内 `Canvas Icons\` 文件夹（可在设置里改路径/尺寸）。
- 相同参数复用同一个文件，不会重复堆文件；**在画布里单独改样式时**会为该节点再生成一个专属文件（文件名带节点后缀），保证不影响其他节点。
- 画布节点是标准的图片节点，可缩放、连线、参与导出；插件会给节点打 `ci-icon-node` 标记，**去掉 Canvas 默认的白底、边框和阴影**，显示为干净的透明图标（选中/聚焦时仍保留强调框，方便操作）。
- 设置页有「清理生成的 SVG」，会删掉该文件夹里的所有自动生成文件（已插入的节点会失去图片，谨慎使用）。

## 命令

- `打开图标面板`：只在该画布已获得焦点时可用，也可从命令面板调起。
- `清理生成的图标文件`：批量删除自动生成的 SVG。
- `清理无引用的图标文件`：扫描全库白板，只删除没有任何节点引用的生成 SVG。

## 设置项

- 图标存放文件夹（默认 `Canvas Icons`）
- 插入尺寸（默认 64）
- 面板尺寸与位置恢复默认
- 导入自定义 SVG / 清空收藏 / 色卡恢复默认 / 清理生成文件 / 清理无引用文件

## 分享 / 发布给其他人

- **最简单：直接发 zip**。对方解压到 `<库>\.obsidian\plugins\canvas-icon-picker\`，重启 Obsidian，在「设置 → 第三方插件」启用即可；zip 里已带全部文件。
- **GitHub Release + BRAT**：把本仓库公开，发一个 tag 与 `manifest.json` 的 `version` 完全一致的 Release（如 `1.2.5`，不要加 `v`），上传 `dist/main.js`、`dist/manifest.json`、`dist/styles.css`。`dist/main.js` 已把 418 个 Material 图标内置，BRAT 只下载这三个文件也能完整使用。
- **Obsidian 官方社区商店**：使用同一套 `dist` 三文件发布 Release，再向 `obsidianmd/obsidian-releases` 提交 PR 登记 `canvas-icon-picker`；仓库还需要 `README.md`、`LICENSE`、`versions.json`。
- 修改图标数据后重新生成发布版：在本项目根目录运行 `python build-release.py`，产物在 `canvas-icon-picker\dist\`。

## 兼容说明

- 依赖 Canvas 视图内部接口（`view.canvas.createFileNode` / `posFromEvt`），与 Canvas Stickers 等插件同一套路径，Obsidian 1.15.0 实测可用。
- 若某版本接口变动，插入会退回「文本卡片嵌入 `![[xxx.svg]]`」的方式；都不可用时会在通知里报错而不是静默失败。
- 仅建议桌面端使用（右键菜单、拖拽依赖指针设备）。
